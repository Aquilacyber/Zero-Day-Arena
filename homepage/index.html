To begin, select a challenge below. Each challenge comes with hints and a walkthrough to guide you if you get stuck. Remember, persistence and creativity are key!

Challenge Overview and How to Access Them

1. Web: SQL Injection Challenge

This challenge is a web application intentionally vulnerable to SQL injection attacks. Your goal is to exploit this vulnerability to bypass authentication or extract sensitive data from the database.

How to Access: The challenge runs inside a Docker container on port 5001. Start it by running docker-compose up in the web-sqli directory, then open http://localhost:5001 in your browser.

2. Crypto: XOR Challenge

This challenge involves decrypting a message that was encrypted using XOR encryption. Analyze the logic, find the key, and recover the flag. Hints and a riddle are provided in the web app to help you solve it!

How to Access: Solve this challenge directly in your browser at http://localhost:5002.

3. Reverse Engineering: CrackMe

This challenge is a Python script designed for reverse engineering. You need to analyze the script's logic to find the correct input or key that passes the validation and reveals the flag.

How to Access: You can now solve this challenge directly in your browser at http://localhost:5003 (or open the script at ../reverse-pyc/crackme.py in a Python environment).

4. Forensics: Steganography

This challenge involves hidden data embedded within an image file using steganography techniques. Download the image, extract the flag using any steganography tool, and verify your flag in the web app.

How to Access: Open the challenge in your browser at http://localhost:5004 to download the image and verify your flag.
